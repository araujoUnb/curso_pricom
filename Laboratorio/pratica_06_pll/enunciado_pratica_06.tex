\section{Fundamentos teóricos}

O PLL é um sistema realimentado que trava a fase e a frequência do seu
oscilador interno na fase do sinal de entrada. Seus três blocos essenciais
são:

\begin{enumerate}
  \item Detector de fase: compara as fases do sinal de entrada
    $\phi_i$ e do VCO $\phi_o$. Saída proporcional a
    $\sin(\phi_i - \phi_o)$.
  \item Filtro de laço: filtro passa-baixas que suaviza a saída do
    detector de fase. Define a largura de banda do laço $\omega_n$.
  \item VCO: oscilador cuja frequência instantânea é controlada pelo sinal
    de erro filtrado, $\omega_\text{VCO}(t) = \omega_0 + K_v\,e(t)$.
\end{enumerate}

A equação em malha fechada para pequenos erros de fase é:
\begin{equation}
  \frac{d}{dt}\phi_e(t) = \omega_i - \omega_0 - K_v K_d\,\phi_e(t),
\end{equation}
onde $K_d$ é o ganho do detector de fase e $K_v$ é o ganho do VCO.
O sistema trava quando $|\omega_i - \omega_0|$ está dentro da faixa de
captura $\Delta\omega_\text{cap} \approx 2\omega_n$.

\subsection*{Etapa 1 -- Flowgraph básico com PLL Frequency Detector (0--12 min)}

\begin{instrucao}[Construção do PLL básico]
\begin{enumerate}[label=\arabic*.]
  \item Crie variável \texttt{samp\_rate} com valor \texttt{32000}.
  \item Crie variável \texttt{loop\_bw} como \texttt{QT GUI Range} com
    \texttt{Start} = 0{,}01, \texttt{Stop} = 0{,}628, \texttt{Step} = 0{,}01,
    \texttt{Default Value} = 0{,}062. A grandeza é a largura de banda do
    laço em rad/amostra.
  \item Adicione \texttt{Signal Source} com \texttt{Output Type} = Complex,
    \texttt{Waveform} = Cosine, \texttt{Frequency} = 1000, \texttt{Amplitude}
    = 1{,}0.
  \item Adicione \texttt{PLL Frequency Detector} e preencha os campos
    exatamente como aparecem no bloco:
    \begin{itemize}
      \item \texttt{Loop Bandwidth} = \texttt{loop\_bw}
      \item \texttt{Max Phase/sample} = \texttt{2*3.14159*2000/samp\_rate}
      \item \texttt{Min Phase/sample} = \texttt{-2*3.14159*2000/samp\_rate}
    \end{itemize}
  \item Adicione \texttt{Throttle} com \texttt{Type} = Float e
    \texttt{QT GUI Time Sink} com \texttt{Type} = Float, 1 canal.
  \item Conecte Signal Source $\to$ PLL Frequency Detector $\to$ Throttle
    $\to$ QT GUI Time Sink.
  \item Execute. A saída do PLL deve convergir para uma constante
    proporcional à frequência de entrada.
\end{enumerate}
\end{instrucao}

\subsection*{Persistência da saída do PLL para análise em Python}

Em vez de ler valores no \texttt{QT GUI Time Sink} a olho -- imprecisão
inevitável de leitura visual --, salve a saída do PLL em arquivo e processe
em Python. As próximas tabelas serão preenchidas com esse fluxo.

\begin{instrucao}[File Sink + análise em Python]
\begin{enumerate}[label=\arabic*.]
  \item Adicione um \texttt{File Sink} com \texttt{File} =
    \texttt{pll\_output.bin}, \texttt{Type} = Float e \texttt{Unbuffered} = Yes.
  \item Conecte a saída do \texttt{Throttle} também ao \texttt{File Sink}, em
    paralelo com o \texttt{QT GUI Time Sink}.
  \item Para cada linha de tabela: ajuste os sliders, execute por cerca de 2 s
    e pare o flowgraph. O arquivo \texttt{pll\_output.bin} é sobrescrito a
    cada execução, então copie ou renomeie antes de mudar de cenário.
  \item Em Python ou Jupyter, carregue o arquivo binário como vetor de floats
    de 32 bits, descarte o transitório inicial -- mantenha os 20\,\% finais
    como regime permanente --, calcule a média do trecho final, que é o
    valor de regime, e o desvio padrão, que é o jitter. Use $f_s = 32000$\,Hz
    para converter índices de amostra em tempo, quando precisar medir o
    tempo de convergência. Exemplo mínimo:
\begin{verbatim}
import numpy as np
data = np.fromfile('pll_output.bin', dtype=np.float32)
fs   = 32000
tail = data[int(0.8*len(data)):]
valor_regime = np.mean(tail)
jitter_std   = np.std(tail)
\end{verbatim}
\end{enumerate}
\end{instrucao}

\subsection*{Etapa 2 -- Observar o processo de lock (12--22 min)}

\begin{instrucao}[Visualização da convergência de fase]
\begin{enumerate}[label=\arabic*.]
  \item Defina a variável \texttt{freq\_in} como \texttt{QT GUI Range} com
    \texttt{Start} = 200, \texttt{Stop} = 1800, \texttt{Step} = 50,
    \texttt{Default Value} = 1000. Em seguida, no bloco
    \texttt{Signal Source}, troque o campo \texttt{Frequency} de 1000
    para \texttt{freq\_in}.
  \item Para cada $f_\text{in}$ da Tabela~\ref{tab:lock}, ajuste o slider,
    execute o flowgraph por $\sim$ 2 s e renomeie \texttt{pll\_output.bin}
    para \texttt{pll\_f500.bin}, \texttt{pll\_f800.bin}, etc. antes da
    próxima execução.
  \item Em Python, pós-processe cada arquivo para extrair o valor de regime,
    a frequência estimada $f_\text{est} = \mu \cdot f_s/(2\pi)$ e classifique
    como locked (1) quando $\sigma/|\mu| < 0{,}02$:
\begin{verbatim}
import numpy as np
fs = 32000
freqs = [500, 800, 1000, 1200, 1500]
for f in freqs:
    data = np.fromfile(f'pll_f{f}.bin', dtype=np.float32)
    tail = data[int(0.8*len(data)):]
    mu, sigma = np.mean(tail), np.std(tail)
    f_est = mu * fs / (2*np.pi)
    locked = int(sigma / abs(mu) < 0.02) if abs(mu) > 1e-6 else 0
    print(f'{f:5d} Hz | regime={mu:.6f} | '
          f'f_est={f_est:.2f} Hz | locked={locked}')
\end{verbatim}
  \item Preencha a Tabela~\ref{tab:lock} com os valores numéricos obtidos.
\end{enumerate}
\end{instrucao}

\subsection*{Etapa 3 -- Efeito da largura de banda do laço (22--35 min)}

\begin{instrucao}[Variar loop bandwidth]
\begin{enumerate}[label=\arabic*.]
  \item Fixe \texttt{freq\_in} = 1000 Hz. Com o slider de \texttt{loop\_bw}
    teste os valores 0{,}010, 0{,}062, 0{,}200 e 0{,}500. Para cada um,
    reinicie o flowgraph, execute por $\sim$ 2 s e renomeie
    \texttt{pll\_output.bin} para \texttt{pll\_bw0p010.bin},
    \texttt{pll\_bw0p062.bin}, etc.
  \item Em Python, extraia $t_\text{conv}$ (5\,\% do valor final, mantido por
    100 amostras seguidas) e o overshoot:
\begin{verbatim}
import numpy as np
fs = 32000
for bw_tag in ['0p010','0p062','0p200','0p500']:
    data  = np.fromfile(f'pll_bw{bw_tag}.bin', dtype=np.float32)
    final = np.mean(data[int(0.9*len(data)):])
    margem = 0.05 * abs(final)
    within = np.abs(data - final) < margem
    idx = next((i for i in range(len(within)-100)
                if np.all(within[i:i+100])), len(data))
    t_conv_ms = idx / fs * 1000
    overshoot = (np.max(np.abs(data)) - abs(final)) / abs(final) * 100
    print(f'{bw_tag} | t_conv={t_conv_ms:.2f} ms | '
          f'over={overshoot:.1f}%')
\end{verbatim}
  \item Preencha a Tabela~\ref{tab:pll}.
\end{enumerate}
\end{instrucao}

\subsection*{Etapa 4 -- Faixa de captura (35--44 min)}

\begin{enumerate}[label=\arabic*.]
  \item Fixe \texttt{loop\_bw} = 0{,}062. Para cada $f_\text{in}$ da

import numpy as np

\subsection*{Etapa 9 -- Bias da estimativa em janela curta sob ruído}

Mesma ideia: reaproveite os \texttt{.bin} da Etapa~5, mas calcule a
média $f_\text{est}$ na janela curta de 50 ms. Mostra que, com janela
curta e ruído alto, $f_\text{est}$ pode estar viesado -- diferente do
valor verdadeiro $f_\text{in} = 1000$\,Hz.

\begin{instrucao}[Bias em janela curta]
\begin{verbatim}
import numpy as np
fs = 32000
n_curto = int(0.05 * fs)
amps = ['0p0','0p3','0p5','1p0']
for amp in amps:
    for bw in ['0p062','0p200']:
        data = np.fromfile(f'pll_a{amp}_bw{bw}.bin', dtype=np.float32)
        short = data[:n_curto]

\begin{atencao}[Atenção -- unidades do PLL]
No bloco \texttt{PLL Frequency Detector} do GNU Radio, os campos
\texttt{Loop Bandwidth}, \texttt{Max Phase/sample} e
\texttt{Min Phase/sample} são todos expressos em radianos por amostra,
