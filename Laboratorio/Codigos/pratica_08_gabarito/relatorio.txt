ETAPA 7: Projeto PCM -- bits necessarios e taxa de bits
=================================================================

  (a) Numero minimo de bits: n >= (SQNR - 1,76)/6,02
      SQNR >=  50 dB  ->  n >=  8.01  ->  9 bits
      SQNR >=  60 dB  ->  n >=  9.67  ->  10 bits
      SQNR >=  70 dB  ->  n >= 11.34  ->  12 bits
      SQNR >=  90 dB  ->  n >= 14.66  ->  15 bits

  (b) Taxa de bits PCM: R = fs * n * (n_canais)
      Voz VoIP wideband (HD Voice)     : fs=16000 Hz, n=16 bits, canais=1  ->  R = 256000 bps = 256.0 kbps = 0.256 Mbps
      Audio de alta resolucao (Hi-Res) : fs=96000 Hz, n=24 bits, canais=2  ->  R = 4608000 bps = 4608.0 kbps = 4.608 Mbps

  (c) Passo e ruido de quantizacao (Vpp = 2 V):
        n |      L |        Delta |  Pq=Delta^2/12
        2 |      4 |  500.0000 mV |     2.0833e-02
        4 |     16 |  125.0000 mV |     1.3021e-03
        8 |    256 |    7.8125 mV |     5.0863e-06
       16 |  65536 |    0.0305 mV |     7.7610e-11
