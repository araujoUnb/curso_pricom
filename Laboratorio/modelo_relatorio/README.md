# Modelo de relatório do aluno

Arquivo base:

- `modelo_relatorio_aluno.tex`

## Como usar

1. Abra o arquivo e preencha os dados no bloco de comandos (`\disciplina`, `\pratica`, `\aluno`, etc.).
2. Escreva o conteúdo nas seções:
   - Introdução
   - Metodologia
   - Resultados
   - Conclusão
   - Referências
3. Compile com:

```bash
pdflatex modelo_relatorio_aluno.tex
```

O logo da UnB já está incluído automaticamente na capa.
