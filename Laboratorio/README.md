# Laboratório PRICOM — GNU Radio

Este diretório organiza **8 práticas de 50 minutos** alinhadas ao cronograma da disciplina FGA0092.

## Sequência das práticas

1. `pratica_01_fft_analise_espectral` — FFT e análise espectral
2. `pratica_02_am_dsb_sc` — Modulação AM DSB-SC
3. `pratica_03_am_convencional` — AM com portadora (DSB+C)
4. `pratica_04_ssb` — Modulação SSB
5. `pratica_05_fm` — Modulação FM
6. `pratica_06_fm_parte2` — Demodulação FM: detector de inclinação e discriminador
7. `pratica_07_pll` — Phase-Locked Loop (PLL)
8. `pratica_08_amostragem_aliasing` — Amostragem e aliasing

## Estrutura de cada prática

Cada pasta contém um `README.md` com:

- objetivo de aprendizagem;
- pré-requisitos;
- roteiro de execução para 50 min;
- entregáveis para relatório;
- rubrica curta de avaliação.

## Template de relatório (LaTeX)

- Arquivo: `template_relatorio_pratica.tex`
- Compilação sugerida: `pdflatex template_relatorio_pratica.tex`
